# Logos de consola

Logotipos de cada sistema, empaquetados con la app para que Freeport sea
autosuficiente (no depende de ES-DE ni de ninguna app externa instalada).

Los nombres de archivo usan los `id` de sistema del catálogo (`n64.svg`,
`psx.svg`, `x360.svg`, `pc.svg`, …). Para añadir un sistema nuevo, deja aquí su
`<id>.svg` y se cargará solo (`src/lib/logos.ts`).

Los logotipos son marcas registradas de sus respectivos propietarios y se
incluyen únicamente con fines de identificación dentro del launcher.
